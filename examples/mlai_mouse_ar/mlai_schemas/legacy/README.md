# MLAI schemas, version 0 (pre-SCENE)

Frozen copy of the MLAI `mice` / `exp` tables and `populate_base`, as they
were on Base-schemas `main` before the shared SCENE layer. Table definitions
and populate logic are unchanged; only formatting and the imports (now
relative) differ.

Kept for migrating existing data to the shared layer. Do not build new
pipelines on them.

Not installed or tested by Base-schemas.
